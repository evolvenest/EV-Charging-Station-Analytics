# EV Charging Station Analytics Dashboard

An interactive **Power BI dashboard** analyzing **10,000 EV charging sessions** to understand energy consumption, charging duration, battery capacity, vehicle models, and charger usage patterns.

## 📊 Dashboard Preview

![EV Charging Station Analytics Dashboard](EV-Charging-Station-Analytics%20dashboard.png)

## 🎯 Project Objective

The objective of this project is to analyze EV charging session data and identify meaningful patterns in:

* Energy consumption
* Charging duration
* Battery capacity
* Vehicle models
* Charger type usage
* State of Charge (SoC)
* Vehicle characteristics

## 🛠️ Tools & Technologies

* **Microsoft Excel** — Data cleaning and validation
* **Power BI** — Data analysis and interactive dashboard
* **Power BI Visualizations** — KPI cards, bar charts, column charts, and donut charts

## 📈 Key KPIs

The dashboard presents the following key performance indicators:

1. Total Charging Sessions
2. Total Energy Consumed (kWh)
3. Average Energy Consumption (kWh)
4. Average Charging Duration (Hours)
5. Average Battery Capacity (kWh)
6. Average Vehicle Age (Years)

## 📊 Dashboard Analysis

The dashboard provides visual analysis of:

* Energy Consumption by Vehicle Model
* Charging Duration by Vehicle Model
* Energy Consumption by Charger Type
* Charging Sessions by Charger Type
* Average Start State of Charge by Vehicle Model

## 🧹 Data Preparation

The dataset was prepared in Excel before importing it into Power BI.

Data validation included:

* Duplicate record checking
* Missing-value checking
* Numerical data validation
* Date/time field verification
* Data type validation

The dataset contained **10,000 charging-session records** with no duplicate rows or blank cells identified during the initial cleaning process.

## 💡 Business Insights

The dashboard helps identify:

* Charging demand across different charger types
* Differences in energy consumption between vehicle models
* Variations in charging duration
* Battery capacity patterns across EVs
* Overall charging-session and energy-consumption trends
